# 🍳 CookMate — Smart Recipe Platform

CookMate is a simple and interactive recipe platform that helps users discover delicious recipes, search by ingredients, and save their favourite dishes.

## ✨ Features

- 🔍 Search recipes by name
- 🥕 Search recipes by ingredients
- 🎲 Surprise Me! random recipe generator
- ❤️ Save favourite recipes
- 💾 Save favourites using localStorage
- 📱 User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- index.html — Page structure
- style.css — Website styling
- script.js — Application logic
- data.js — Recipe data

## 🚀 How to Run

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select Open with Live Server.

## 🎯 Project Goal

CookMate makes finding and discovering recipes easier by helping users explore dishes based on their preferences and available ingredients.
